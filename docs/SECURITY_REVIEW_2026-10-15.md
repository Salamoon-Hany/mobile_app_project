## حدود المحاولات

- تسجيل الدخول: 5 محاولات لكل identifier في نافذة 15 دقيقة؛ النجاح يمسح عدّاد identifier.
- مسارات auth: 30 طلبًا لكل IP/دقيقة، بالإضافة إلى 120 محاولة دخول لكل IP/15 دقيقة.
- API العام: 300 طلب لكل IP/دقيقة؛ حساب Firebase: 150 قراءة و30 كتابة/دقيقة، و10 عمليات مالية/دقيقة.
- العدادات ذرية ودائمة في D1، والمفاتيح تعتمد على SHA-256 بدل تخزين الإيميل أو IP بالنص. النوافذ ثابتة؛ دي حدود للتطبيق، وليست وعدًا بمنع DDoS أو بديلًا لحماية مزوّد الهوية.
- API يحمل `no-store`؛ دور الحساب وهوية العميل والعامل يؤخذان من Firebase والخادم، وليس من UID أو role يرسله العميل.

- ملفات Android XML سليمة نحويًا. لم يُنتج AAB/APK موقّع، ولم يُختبر Android على جهاز حقيقي. لم يتوفر اختبار متصفح فعلي للـCSP والكاميرا في بيئة التنفيذ؛ اختبارات الأدوات لا تثبت نجاح كاميرا موبايل حقيقي.

## باقي قبل إطلاق عام أو Play Store

1. **إعدادات Firebase الفعلية:** التأكد من نشر Firestore Rules الموجودة، وضبط حصص Identity Toolkit وEmail Enumeration Protection ومراجعة App Check. لم تتوفر صلاحية Console هنا لتأكيدها. حد التطبيق يمكن تجاوزه باستدعاء Firebase مباشرة؛ لذلك إعدادات المزوّد لازمة قبل إطلاق عام.
2. **أدوات الاختبار:** `braces <=3.0.3` ليس لها إصدار مُصلَح متاح وقت الفحص، ومعها `chokidar` و`firebase-tools` كمسارات تبعية؛ وOpenTelemetry Core 1.x المستخدم داخل Pub/Sub بالأداة عليه advisory آخر. لم أفرض ترقية major غير متوافقة لإخفاء التحذير. المحاكيات مربوطة بـ127.0.0.1 وتستخدم مشروع `demo-mobile-app` فقط؛ لا تنشر أدوات التطوير أو تقبل منها ملفات/globs غير موثوقة. إعادة فحصها وترقيتها لازمة عند توفر إصلاح متوافق.
3. **نسخة Android:** تسجيل تطبيق Android في Firebase، application ID حقيقي وملفات الإعداد، مفتاح توقيع يحتفظ به المالك، واختبار الجهاز والكاميرا والاسترجاع. إعداد Firebase الحالي Web فقط. اتصال APK بموقع خاص يحتاج تصميم وصول مناسب؛ ممنوع تضمين service bypass token داخل التطبيق.
4. **سياسات المتجر:** مراجعة سياسة الخصوصية والاحتفاظ بالبيانات وData Safety ورابط حذف الحساب الخارجي ومتطلبات target SDK الحالية. لا يمكن إعلان جاهزية Play Store من بناء Web وحده.
5. **المال:** Add Funds والسحب ما زالوا تجريبيين؛ لا تحصيل نقدي ولا تحويل حقيقي ولا إرسال إيميلات دفع. `DEMO_FUNDS_ENABLED=true` مقصود للنسخة الخاصة الحالية فقط، وليس تصريحًا بإطلاق محفظة مالية عامة. السحب 5% طلب مسجل للمراجعة، وليس تحويلًا تم تنفيذه.
6. **تحقق تفاعلي:** تجربة CSP وتسجيل الدخول والكاميرا على متصفحات وأجهزة فعلية. لم أختبر كلمة مرور صاحب التطبيق أو أنشئ له طلبات أو أموالًا أو أرسل SMS/إيميلات للاختبار.
